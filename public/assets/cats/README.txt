Drop your animated cat .gif files into this folder!

Supported state filenames (all optional - any missing state automatically falls back to idle.gif or the default pixel cat):
- idle.gif         (Default sitting / breathing cat)
- happy.gif        (When petted or in a happy mood)
- eating.gif       (When fed a food treat)
- hungry.gif       (When fullness drops to 0)
- sleepy.gif       (When resting / sleepy)
- celebrating.gif  (When a task/goal is completed)
